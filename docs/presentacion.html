Neumann Miguel Angel · 2026

Node.js 24 TypeScript 6 Express 5 Prisma 7 PostgreSQL

¿Qué es?

REST API que centraliza el envío de notificaciones a múltiples plataformas, con autenticación, autorización por roles y límite diario por usuario.

// notification.service.ts — entrega paralela
const results = await Promise.allSettled(
  platforms.map((platform) => {
    if (platform === 'DISCORD')  return sendDiscordMessage(content, username);
    if (platform === 'TELEGRAM') return sendTelegramMessage(content, username);
    if (platform === 'SLACK')    return sendSlackMessage(content, username);
  })
);
// ↑ Si una plataforma falla, las demás siguen igual
